# Client-winning portfolio refinement

## Goal

Make the portfolio feel immediately credible to potential freelance clients and guide them toward a clear project enquiry without changing the established visual style.

## What I’ll improve

- Rewrite the opening message around client outcomes: professional WordPress websites, online stores, redesigns, speed improvements, and reliable ongoing support.

- Make the primary action more direct and low-friction with email and WhatsApp enquiry options.

- Strengthen the selected work section with real website previews, clearer project context, and visible “Visit website” actions.

- Add a concise services section so clients can quickly match their need to an offer.

- Reframe the experience, process, and toolkit around trust, communication, testing, handover, and business value.

- Add a focused “Why work with me” section using only evidence already provided, with no invented testimonials or claims.

- Add a short client FAQ covering project types, remote work, communication, WordPress handover, and ongoing support.

- Refine the final contact area into a stronger enquiry invitation while preserving the existing charcoal, off-white, lime, and coral design.

## Technical details

- Keep the current one-page structure, typography, colors, animations, and mobile menu.

- Use screenshots from the listed live projects where they are publicly accessible; otherwise retain a polished text presentation.

- Keep contact actions as direct links, with no database or sign-in required.

- Preserve responsive behavior, accessibility, and existing page metadata while sharpening its freelance-client positioning.

- Verify the completed page on desktop and mobile, including navigation, external project links, email, phone, and WhatsApp actions.
